# Phishing Triage Checklist (Non-Expert Version)

A quick-reference checklist any employee can use to evaluate a suspicious message
in under a minute, without needing security training. Answer each question — the
more "yes" answers, the more likely the message is malicious.

## Step 1 — Check the sender
- [ ] Does the "From" name (e.g., "IT Security," "CEO") not match the actual email
      address shown when you hover over or expand it?
- [ ] Is the domain slightly different from the real company/brand domain
      (misspelling, extra words, wrong extension, unfamiliar subdomain)?
- [ ] Is this someone who has never emailed you before, or an unexpected reply to
      a thread you don't remember starting?

## Step 2 — Check the tone and ask
- [ ] Does the message create urgency (a countdown, "immediately," "before it's
      too late")?
- [ ] Does it invoke authority (CEO, IT, law enforcement, government) to discourage
      questions?
- [ ] Does it ask you to keep the request secret or bypass a normal process
      (approvals, procurement, verification)?
- [ ] Does it promise a reward, refund, or prize you didn't expect?
- [ ] Does it threaten a negative consequence (account suspension, legal action,
      job risk) if you don't act now?

## Step 3 — Check the content
- [ ] Does it ask for a password, MFA code, payment details, or other sensitive
      information directly?
- [ ] Does it include a link that looks off when you read it slowly, right to left
      (real company name buried in the middle, not the actual domain)?
- [ ] Does it include a QR code you weren't expecting?
- [ ] Does it include an attachment with an unusual extension (.iso, .js, .scr) or
      one you didn't ask for?
- [ ] Does it give you only a phone number to call, with no other way to verify?

## Step 4 — Decide
- **0 boxes checked:** Likely safe. Proceed normally.
- **1–2 boxes checked:** Suspicious. Do not click, reply, or call. Verify through a
  separate, known channel (e.g., call the person using a number from the company
  directory, not the message).
- **3+ boxes checked, or any request for credentials/payment/MFA:** Treat as
  malicious. Do not interact with it at all. Report it immediately using the
  official reporting channel and let the security team purge it from other inboxes.

## The Golden Rule
**Pause → Verify → Report.**
Never verify a suspicious request using contact details provided in the suspicious
message itself — always use a number, email, or channel you already know to be real.
